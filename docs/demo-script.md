# 2–3 minute demo script

1. Open the deployed ZoroMart home page and show the black-and-gold marketplace design.
2. Register/log in as a Seller, create a listing with name, description, price, stock, category and image URL.
3. Log out and log in as a Buyer; search/filter the new listing, add it to the cart, adjust quantity and show the server-calculated total.
4. Checkout. Explain that payment is intentionally mocked and no real money is collected.
5. Open Order History and show the stored order. As Admin, update the status to Delivered; return as Buyer and submit a star rating/review.
6. Show Seller incoming orders and Admin user/order views.
7. Ask the FAQ chatbot a product/cart/order question; show `/api/v1/health` and explain H2 persistence, BCrypt, sessions and prepared statements.
8. Keep a screen recording as backup in case the live host is unavailable.
